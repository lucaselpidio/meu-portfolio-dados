## Como é feito

- HTML, CSS e JavaScript puros, sem framework e sem build: o GitHub Pages publica a pasta como está.
- Tema claro e escuro: segue o sistema do visitante, com botão para trocar (a escolha fica salva no navegador).
- Responsivo, acessível (navegação por teclado, link para pular ao conteúdo, textos alternativos) e respeita quem prefere menos animação.

```
index.html          a página (português)
en/index.html       a versão em inglês (mesmo CSS e JS; manter as duas em sincronia)
css/estilo.css      estilos e temas
js/site.js          tema, menu do celular, seção ativa e animação de entrada
img/projetos/       capturas das demonstrações (tema escuro)
img/og.png          prévia do link ao compartilhar (LinkedIn, WhatsApp); og-en.png para a versão em inglês
curriculo/          currículo em PDF (português e inglês)
```

Para ver localmente, abra `index.html` no navegador.
